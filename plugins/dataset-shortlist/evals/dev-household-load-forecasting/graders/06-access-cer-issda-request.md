PASS if the final answer states that the Irish CER Smart Metering Project electricity data is not an open download but must be requested from the Irish Social Science Data Archive (ISSDA), for example by submitting an ISSDA data request form that is reviewed before access is granted, and that it is provided for non-commercial research or teaching. Mentioning the ISSDA end user licence, or that ISSDA supplies data only for use in the EEA and countries with an EU adequacy decision, is welcome but not required. FAIL if the answer does not mention the CER data, describes it as freely downloadable, or says nothing about how access to it is obtained.
