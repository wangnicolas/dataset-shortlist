PASS if the final answer states that PASTIS (Panoptic Agricultural Satellite TIme Series) can be downloaded openly, without an application, and that its licence is Creative Commons Attribution (CC BY, version 4.0). Saying that it is hosted on Zenodo is welcome but not required. FAIL if the answer does not mention PASTIS, gives no licence for it, gives a different licence (for example a non-commercial or share-alike one), or says access must be requested.
