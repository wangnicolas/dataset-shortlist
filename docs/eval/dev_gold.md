# Development set: gold answers and evidence

Built 2026-11-11 under `docs/EVAL_PROTOCOL.md`, without opening anything under
`plugins/dataset-shortlist/skills/`. Every fact below was fetched in this session
from the official page or the paper named in the Source column (date checked
2026-11-11 for all rows). Quotes are verbatim from the fetched page, paper
abstract or repository metadata (Zenodo, figshare, Dataverse, data.gov.au and
GitHub API records are quoted as `field: value`). The grader files live in
`plugins/dataset-shortlist/evals/<case>/graders/`.

Families: **must_find** rows back the recall graders (one row for published
use, one for access and licence); **access** rows back the access graders;
**trap** and **long_tail** rows back those graders.

Why NWICU and SICdb count as fitting while the 2012 challenge data is the
trap: the 2019 challenge itself operationalises Sepsis-3 suspicion of
infection as "the ordering of blood cultures or IV antibiotics" together with
"a two-point change in the patient's Sequential Organ Failure Assessment (SOFA)
score" (https://physionet.org/content/challenge-2019/1.0.0/). NWICU and SICdb
carry timestamped drug administration plus labs and vitals, so an onset time can
be derived under that rule; the 2012 challenge data carries neither antibiotics
nor cultures and stops at 48 hours. Neither NWICU nor SICdb has a published
sepsis-onset study that was found in this session; they are long-tail items
(no published-use requirement), not must_find.
