# F2: Dataset-registry and literature API probe (live, 2026-11-11)

UA used everywhere: `dataset-metadata-client/0.1`. No keys, no logins, no mailto. All calls below were actually made today (about 4-9 per service). Samples (truncated, untrusted data) are in `<scratch>/research/api_samples/<service>_sample.json`; full raw responses are in `../raw/`.
Q1 = "ICU mortality prediction time series", Q2 = "voice recordings Parkinson's disease", Q3 = "satellite imagery crop yield". "Docs" = what a WebFetch of the cited page actually showed; many doc pages were thin or failed, those items are UNVERIFIED.

## 1. DataCite REST: 200, no key
`curl -sG -A "$UA" "https://api.datacite.org/dois" --data-urlencode "query=voice recordings Parkinson's disease" --data-urlencode "resource-type-id=dataset" --data-urlencode "page[size]=5"`
- Auth: none for reads (docs https://support.datacite.org/docs/api: public API "accessed without authentication"). Rate limit, page max, terms: UNVERIFIED (docs pages did not state them).
- Fields (`data[].attributes`): `titles`, `descriptions`, `doi`, `url`, `rightsList` (SPDX id/URI), `version`, `sizes`, `formats`, `updated`, `publicationYear`, `publisher`, `viewCount/downloadCount/citationCount`, `types.resourceTypeGeneral`, `relatedIdentifiers`. `meta.total` gives hit count. No explicit open/restricted flag (only `rightsList`, and often empty); `sizes`/`version` frequently empty.
- Ranking (total hits Q1/Q2/Q3 = 3/23/36). Q1: NEUROFLOW early ICU delirium TCN; "data of BRITS_RA_TA" x2. Q2: VOC-PD Mandarin PD speech x2; "Automated Detection of PD Using CNN" x2; Arabic PD Speech Dataset. Q3: Kothen 2011/2012 EnMAP flight campaign; "Smart Agriculture: intelligent decision support..." x2; "Digital agricultural finance in Uzbekistan" x2 (off-topic).
- Pitfalls: query is AND-like so long queries return few hits; many records are duplicated (concept DOI + version DOI, or same paper twin records); aggregates Zenodo/figshare etc. so overlaps with those; off-topic items surface.

## Recommendation: support first (7 sources)
1. **OpenAIRE Graph** (dataset type): best relevance on all three queries, cross-registry dedup, `bestAccessRight`, embargo date, per-instance licence, citation indicators; no key.
2. **DataCite**: broadest DOI-level coverage (Zenodo, Dryad, Figshare, institutional repos), `rightsList`, `updated`, counts; no key. Use it for existence verification of any DOI.
3. **Zenodo**: highest recall for ML datasets, explicit `access_right` (open/restricted/embargoed/closed), licence id, file sizes, stats; 30 search req/min and 25 per page anonymous; CC0 metadata.
4. **Hugging Face Hub**: where ML datasets live, explicit `gated` flag, downloads, licence tag; but substring search only (decompose queries into single keywords) and many licences missing.
5. **Harvard Dataverse** (and the Dataverse protocol generally): good metadata once you fetch the dataset record (licence, per-file `restricted`), but poor ranking; use with `type=dataset` and verify relevance.
6. **Dryad**: curated, mostly open, licence plus metrics in the search response; use short queries.
7. **Domain/benchmark pair by need**: **OpenNeuro** (neuroimaging) and **UCI + OpenML** (small tabular benchmarks, with OpenML detail for licence/URL). Add **Kaggle** only as an optional, key-based source, because anonymous access works today but is undocumented. Use **re3data** to name domain repositories (PhysioNet, etc. appear there) when no source covers the field. Use **Crossref** and **OpenAlex** (with a free key) for "papers that use this dataset"; Semantic Scholar only with a key. Figshare and data.gov are second tier (figshare search is noisy; data.gov is US-government only and needs the new `/search` endpoint). GEO is for omics only.

## Which fields are reliable as ground truth
- Access condition (reliable): Zenodo `metadata.access_right`; Hugging Face `gated` (False/auto/manual); Dataverse per-file `restricted` and `fileAccessRequest`; OpenAIRE `bestAccessRight`/`embargoEndDate` (aggregated, so cross-check); Dryad/OpenNeuro by platform policy (public only, UNVERIFIED policy). Not reliable: DataCite (no access flag), Kaggle `isPrivate` (privacy not access), UCI (no field), Figshare search (none).
- Licence (reliable): Zenodo `license.id`; Dataverse `license.name/uri` (dataset call); Dryad `license` URL; DataCite `rightsList` when present (SPDX); OpenML `licence` (coarse). Medium: Kaggle `licenseName` and HF `license:` tags (uploader-declared, can be wrong on re-uploads; HF often missing; "other"/"Other (specified in description)" needs human reading). Absent in search output: Figshare, Dataverse search, UCI, GEO, data.gov (DCAT blob only).
- Never treat credentialed datasets (MIMIC, eICU, Bridge2AI) found on HF/Kaggle/Zenodo re-uploads as openly licensed: the declared licence on a mirror does not override the source's data use agreement.
- Existence: a 200 on the DOI record (DataCite/Zenodo/Dataverse) or on the per-record endpoint is the check; search hits alone can be stale (OpenNeuro deleted datasets still appeared as edges).
