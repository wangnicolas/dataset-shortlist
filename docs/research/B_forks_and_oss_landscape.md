## Verdict

(a) **Does any repo cover about 80% of the target? No, not with the evaluation discipline the target asks for.** Stage coverage alone is high: ARIS, AutoResearchClaw, FAROS, EvoScientist and Orchestra each touch lit review, experiments and paper writing, and ARIS/AutoResearchClaw already ship a Claude Code plugin or ACP-CLI. But (i) none of them has the autoresearch core contract (frozen `prepare.py`, one editable `train.py`, fixed 5-min budget, keep/git-reset, `results.tsv`) as the enforced centre; they are either Markdown prose loops or large pipelines; (ii) dataset discovery and EDA/feature selection are almost uncovered as agent stages (data-to-paper is the only one that starts from raw data and does EDA, but it was last pushed 2025-07-19, has no experiment loop, and is not a Claude Code skill pack); (iii) integrity is mostly LLM-run audits (ARIS) or Docker/sealed graders in infrastructure-heavy tools (CORAL, AI-Scientist-v3, AutoResearchClaw), none of which are a light skill pack with hash-locked eval. Forking ARIS would give you the packaging and review skills, but its centre of gravity (cross-model review, 80+ skills, theory/patents/rebuttals) is far from a small frozen-harness design; forking karpathy/autoresearch gives you the loop but no license file and no multi-stage scaffolding. Recommendation: build new, but borrow patterns openly (plugin layout from ARIS/CORAL/Orchestra, sealed eval from AI-Scientist-v3/CORAL, dev/held-out split from Arbor, run viewer from pi-autoresearch/AI-Scientist-v3), and depend on or call out to existing tools for lit review (paper-qa, alphaXiv) instead of rebuilding.

(b) **Gaps a new project could credibly own**
1. A *data-first* front end: dataset selection + EDA + feature selection + leakage checks as first-class stages feeding a frozen harness. Closest thing is a 17-star tabular fork (ajzhanghk/autoresearch-glm) and data-to-paper (stale).
2. **Evaluation integrity as code, in a small package**: content-hash of `prepare.py`/data/splits, read-only mount or permission drop, held-out test touched only once at the end (Arbor/AI-Scientist-v3 do pieces of this in heavy frameworks; ARIS does audits by LLM). A per-run "integrity report" artifact (hash chain, leakage test, number-to-log trace as in data-to-paper) is a differentiator.
3. A Claude Code plugin with a small Python CLI that gives a deterministic `results.tsv` + `agent-report` and works without Docker or a GPU cluster (default CPU/tabular task; AI-Scientist-v3's CPU `circpack` example shows demand for a zero-GPU quickstart).
4. Honest human baselines: compare against published/Kaggle human leaderboard or a human-tuned baseline on a fixed task set, with seeds and CIs. Current claims compare agents with agents (Arbor) or are anecdotal (accepted workshop paper).
5. Reproducible traceability from paper sentence to run row (data-to-paper idea, rarely combined with an experiment loop).

(c) **Showcase patterns tied to adoption (stars are correlational; I did not verify causality)**
- Single hero artifact from the base repo: karpathy's `progress.png` (metric-vs-experiment curve with kept points) sits above 99.8k stars; copy that pattern, one honest progress chart.
- Zero-cost "watch it run" demo: Arbor `arbor replay --demo` (30 s, no API key) plus an in-browser live demo; AI-Scientist-v3 `agsci inspect start`; pi-autoresearch live dashboard/widget; autoresearcherUI cockpit screenshot.
- A gallery of finished generated outputs: AutoResearchClaw paper showcase (8 papers/8 domains with thumbnails), AI-Scientist v1 `example_papers/*.pdf` + full run archive on Drive, data-to-paper example manuscript PDF.
- Short animated hero GIF: Orchestra `promo.gif`, CORAL `demo.gif`, SuperARIS 21-second demo, data-to-paper icon/page-flipping GIFs.
- Pipeline diagram at the top (AutoResearchClaw `framework_v2.png`, EvoMap workflow SVG, CORAL architecture diagram).
- One-line install / three-command quick start: `npx @orchestra-research/ai-research-skills`, `pip install arbor-agent`, `/plugin marketplace add ...` (CORAL, Orchestra, ARIS).
- Paper or benchmark behind it: arXiv badges on nearly all high-star systems (AutoResearchClaw, ARIS HF Daily Paper, CORAL COLM 2026, K-Dense arXiv 2609.00065, AI-Scientist-v3).
- Authenticity signals: test-count badge (2699 tests), changelog cadence (ARIS), explicit caveats (AI-Scientist-v2 admits lower success than v1) .
- Weak spots to avoid: README bloat (ARIS 1,829 lines, HKUDS 1,100) and unverified superlatives.
